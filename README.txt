ПОДХОД — полная сборка v4
Распакуйте архив и загрузите ВСЕ файлы непосредственно в корень репозитория, заменив предыдущие index.html, app.js, style.css, sw.js, manifest.webmanifest и icon.svg. Старые picker.js/picker.css больше не нужны: барабан уже встроен. .nojekyll также включён.
GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save.
Перед обновлением сделайте экспорт истории. Оставьте тот же адрес сайта: данные используют прежний ключ podhod-v1. Импорт старой копии поддерживается с проверкой; некорректные данные отклоняются. Старое хранилище не перезаписывается, если проверка не пройдена.
После публикации откройте сайт с интернетом, затем закройте и откройте снова. Очистка данных Safari не нужна.
План: прежний сокращённый черновик на 4 дня, не программа для мамы. Недели 1–2: изоляция 2/основные 3; 3–4: 3/3; 5–6: 3/4; 7–8: 4/4. Далее последний этап сохраняется. При добавлении подхода вес не повышается. Шаг прогрессии задаётся отдельно. Барабан без заданного шага использует 2.5 кг только для ввода.
Безопасность: CSP, без сторонних библиотек и innerHTML, валидация импорта/хранилища, лимит файла 2 МБ. Данные локальные и не зашифрованы. Хостинг видит запросы файлов, история на сервер не отправляется. Резервные копии не публикуйте.
Офлайн: после первого полного открытия онлайн проверьте авиарежимом. Таймер пересчитывает время при возврате; звук на заблокированном iPhone не гарантирован. Вибрация отсутствует. Клавиатура для веса и повторов заменена барабаном. Ручной ввод есть отдельной кнопкой.
На физическом iPhone не тестировалось.
