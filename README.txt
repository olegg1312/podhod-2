ПОДХОД v2 — тёмная версия

Файлы: index.html, style.css, app.js, sw.js, manifest.webmanifest, icon.svg. Загрузите все в корень публичного репозитория GitHub, затем Settings -> Pages -> Deploy from a branch -> main -> / (root). Откройте адрес в Safari -> Поделиться -> На экран Домой.

Безопасность: нет внешних библиотек, аналитики и отправки данных; интерфейс строится через textContent/value, без innerHTML; импорт и локальные данные полностью проверяются; ограничен размер файла и число записей; добавлен CSP. Хранилище не шифруется. Сервисный worker кэширует файлы приложения. Для изоляции localStorage лучше отдельный origin, а не папка внутри чужого сайта на том же домене. Версия не проверена на физическом iPhone.

Изменения прогрессии: подходы по этапам 2/3, 3/3, 3/4, 4/4. Шаг прибавки задаётся для упражнения. Если число подходов выросло, вес сохраняется. План пока черновой.

Таймер: пересчитывается по времени при возвращении в приложение; звук при заблокированном экране не гарантирован.
